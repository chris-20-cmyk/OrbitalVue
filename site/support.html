Troubleshooting

Start with what changed.

These checks cover the current cross-platform foundation. Controls can vary while each Store build is completed.

Open a public issueCheck releases
Protect your source.Never post playlist URLs, provider usernames or passwords, access tokens, custom headers, private server addresses, or personal media names in a public issue.

Confirm the same URL or file still works in a trusted player, then re-enter it without sharing it publicly. For a URL source, check whether the provider requires a username, password, token, or custom request header. Local files must remain available at the path you imported.

Try the Smart or Balanced buffer profile, keep hardware decoding enabled unless the GPU driver is the suspected cause, and compare one channel in another player on the same PC. If every live channel is affected, note the stream format, player engine, buffer event count, and whether the issue changes when the app loses focus.

Personal media-center integration is a one-time premium feature where platform commerce is supported. Confirm the correct Store account is active and use Restore Purchase when available. LG webOS remains a free lane with premium safely locked until a verified commerce path exists.

Use the in-app update path only for the Windows distribution that supports it. Store-managed builds update through their platform Store. Keep OrbitalVue closed while the replacement package is installed and never download an update from an unverified third-party link.

Press Back once to close the active dialog or overlay, then use the directional pad to re-enter the channel list or player controls. When reporting the issue, name the TV platform and model year and describe the last control that had visible focus.

Include the OrbitalVue version, platform and operating-system version, source type without its address, live or on-demand content type, player engine, playback setting changes, and exact steps to reproduce. Review any diagnostic export before attaching it.
